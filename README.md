# CSC649: My First Python Experiment

## What it does
This program accepts a sentence and displays:
- Word count
- Character count (including spaces)
- A message if no input is given

## How to run
1. Open terminal in project folder.
2. Run: `python main.py`

## Test results
- Input: "Hello world from CSC649" → Word count: 4, Character count: 23
- Input: "" → "You did not enter a sentence."
- Input: "   Python   is   fun   " → Word count: 3, Character count: 19

## Limitation
- Counts characters including spaces, but does not exclude punctuation.
